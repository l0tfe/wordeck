# Wordeck

Карточки для изучения английских слов: NGSL, Oxford 3000 и Oxford 5000 с переводом на русский.
Смахни влево - знаю, вправо - учить. Тренировка, интервальные повторения, словарь по разделам и темам.

Открыть: https://l0tfe.github.io/wordeck/

На iPhone: открыть ссылку в Safari -> «Поделиться» -> «На экран „Домой“».
